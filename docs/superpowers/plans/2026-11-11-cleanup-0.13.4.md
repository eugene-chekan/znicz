> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** No blink when an overlay closes on Stage; the autostarted player never lingers as a zombie; tests clean up their temp files (#79); edition 2024.

**Tech Stack:** Rust, ratatui 0.30 (crossterm 0.29 via `ratatui::crossterm`), ratatui-image 11, tempfile 3.

```rust
fn run_loop(&mut self, terminal: &mut ratatui::DefaultTerminal) -> color_eyre::Result<()> {
    let mut repaint = false;
    loop {
        self.poll_player_events();
        self.toasts.tick();

        let state = self.player.state();
        if repaint {
            repaint = false;
            // Clear and redraw as one update, so the terminal never shows
            // the blank screen in between (ignored where unsupported).
            execute!(terminal.backend_mut(), BeginSynchronizedUpdate)?;
            terminal.clear()?;
            let drawn = terminal.draw(|frame| views::render(frame, self, &state));
            execute!(terminal.backend_mut(), EndSynchronizedUpdate)?;
            drawn?;
        } else {
            terminal.draw(|frame| views::render(frame, self, &state))?;
        }

        // … event handling unchanged …
            let overlays_after = self.overlays();
            if needs_full_redraw(self.view, overlays_before, overlays_after) {
                if cover_needs_retransmit(self.picker.as_ref().map(|p| p.protocol_type())) {
                    self.cover_draw_key = None;
                }
                repaint = true;
            }
        // …
    }
}
```

Imports: `use ratatui::crossterm::execute;` and `use ratatui::crossterm::terminal::{BeginSynchronizedUpdate, EndSynchronizedUpdate};` — use the `ratatui::crossterm` re-export (crossterm 0.29, the backend's version), not the workspace `crossterm` 0.28. If `picker.protocol_type()` returns `ProtocolType` by value use as shown; adapt if it returns a reference.

- [x] **Step 1: Test** (Linux only, in `daemon.rs` tests module; create `#[cfg(test)] mod tests` if missing):

```rust
#[cfg(target_os = "linux")]
#[test]
fn an_exited_player_does_not_stay_a_zombie() {
    // `true` ignores the `player` argument and exits at once.
    spawn_detached_player_exe(std::path::Path::new("true"), None, None).unwrap();
    let deadline = std::time::Instant::now() + std::time::Duration::from_secs(5);
    loop {
        if zombie_children().is_empty() {
            break;
        }
        assert!(std::time::Instant::now() < deadline, "zombies: {:?}", zombie_children());
        std::thread::sleep(std::time::Duration::from_millis(20));
    }
    // Give a not-yet-reaped child time to show up as a zombie, then check again.
    std::thread::sleep(std::time::Duration::from_millis(200));
    assert!(zombie_children().is_empty(), "zombies: {:?}", zombie_children());
}

#[cfg(target_os = "linux")]
fn zombie_children() -> Vec<String> {
    let me = std::process::id().to_string();
    std::fs::read_dir("/proc")
        .unwrap()
        .filter_map(|e| std::fs::read_to_string(e.ok()?.path().join("stat")).ok())
        .filter(|stat| {
            // `pid (comm) state ppid …`; comm may contain spaces, so split after ')'.
            let rest = stat.rsplit_once(')').map(|(_, r)| r).unwrap_or("");
            let mut fields = rest.split_whitespace();
            fields.next() == Some("Z") && fields.next() == Some(me.as_str())
        })
        .collect()
}
```
